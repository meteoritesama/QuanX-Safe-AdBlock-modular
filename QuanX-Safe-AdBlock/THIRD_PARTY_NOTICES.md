# THIRD_PARTY_NOTICES

## Runtime

Quantumult X runtime does not execute JavaScript from third-party repositories.

## YouTube Lite rule provenance

The YouTube Lite endpoint patterns were cross-checked against publicly maintained Quantumult X
YouTube rules that credit DivineEngine, app2smile, Maasea and VirgilClyne. V3.1 does not include
their response-body JavaScript; it keeps only the low-overhead native URL rewrite/reject layer.

## Bilibili

The Bilibili runtime script remains the project's own minimal cleaner from V3.
